Privacy Policy - GNSC Workbench

Last updated: 20 November 2026

Scope

GNSC Workbench is a personal desktop application used by its owner only. This policy explains how it uses Google user data.

Google data the app accesses

The app requests a single scope: https://www.googleapis.com/auth/calendar.events. With it, the app looks up, creates, updates and deletes events in the owner's primary Google Calendar, and only the roster events that the app itself created.

How the data is used

  • Calendar access is used only to show the owner's work roster in the owner's own calendar.
  • The app does not read other calendar events for any other purpose.
  • No Google data is sold, used for advertising, or used to train AI models. Owner-configured cloud storage and backups are described below.

How the data is stored

The Google sign-in token and a small record of synced roster events are stored in the owner's configured data folder. That folder currently uses Microsoft OneDrive, so these files may also be synchronized to OneDrive and retained in the owner's backups. Calendar synchronization communicates with Google's authentication and Calendar services. The public website contains documentation only, not tokens or roster data.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the active local token file stops this installation from using that file, but does not revoke tokens held in backups or other copies. Revoke access in the Google account to invalidate the authorization, and remove retained copies from local storage, cloud storage and backups as needed.

Google API Services User Data Policy

GNSC Workbench's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
