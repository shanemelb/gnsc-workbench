GNSC Workbench

A personal desktop tool for one support engineer's work roster.

What it does

GNSC Workbench runs only on the owner's own Windows PC. It keeps the owner's work roster (weekend work, on-call weeks, leave, public holiday work, days in lieu) in a local database.

The Google Calendar feature copies those roster entries into the owner's own Google Calendar, so the roster can be seen on a phone. It creates, updates and removes only the events that the tool itself made.

Who can use it

This is a single-user personal application. It is not offered to the public and has no sign-up. The only Google account that connects to it is the owner's account.

Google data

The app asks for one permission: https://www.googleapis.com/auth/calendar.events (view and edit events in your calendars). It is used only to write roster events into the owner's primary calendar. Details are in the Privacy Policy.
